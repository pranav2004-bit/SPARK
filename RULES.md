# AptLogic — Engineering & Design Rules

These 5 rules are non-negotiable. Every execution and implementation must strictly follow them.

---

## RULE 1 — WORLD CLASS PREMIUM PRESENTATION
Every interface and every piece of content must meet a world-class premium standard.
Mediocre screens, cluttered layouts, and low-quality UI are build blockers — not cosmetic issues.
If it does not feel premium, it does not ship.

---

## RULE 2 — INDUSTRIAL STANDARDS, ENTERPRISE LEVEL, PRODUCTION READY
Every line of code, every API, every schema must meet enterprise-grade standards from day one.
Security, reliability, performance, and maintainability are non-negotiable engineering requirements.
No technical debt in core system design.

---

## RULE 3 — SCALABLE TO 20,000+ CONCURRENT USERS
Architecture decisions must account for 20,000+ concurrent users from the first line of code.
Indexes, connection pooling, caching strategy, and async patterns must be in place — not as future upgrades.

---

## RULE 4 — APPLE-STANDARD UI/UX — CLEAN, MINIMAL, VALUE-DRIVEN
Clean, minimal, professional. Value over decoration. Function over form. Quality over quantity.
No unnecessary elements. Every pixel must earn its place. Fully responsive across all devices.

---

## RULE 5 — USER EXPERIENCE IS THE TOP PRIORITY [NON-NEGOTIABLE]
UX is the single most important requirement. Every other consideration is secondary.
If a feature conflicts with UX quality, the feature is redesigned. This rule cannot be overridden.
